# Higher Categories I
This is an attempt to TeXify Fabian Hebestreit's lecture notes for [Higher Categories I](https://sites.google.com/view/fabian-hebestreit/home/lecture-notes#h.7codatyfu5s8) course.

I was inspired by the [work](https://github.com/FlorianAdler/AlgebraBonn/tree/master/K-Theory) of Ferdinand Wagner on TeXifying Fabian's lecture notes for Algebraic K-Theory course.

> [!NOTE]
> I'm not a mathematician, so the only changes I make are small errors/typos corrections and small stylistic improvements.
>
> I'm using these lecture notes for my own self-study, so my main goal for now is to make them a bit more readable while sticking with original style. My LaTeX skills are pretty low anyway.
>
> Not using `theorem` environment is somewhat intentional for now.
